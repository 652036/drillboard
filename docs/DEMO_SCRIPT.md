# 2–3 minute demo script

1. Open the **Checkout outage** scenario. Point out the shared clock, metrics, active injects, objectives, resources, and empty response-review lane.
2. Keep **Coach** selected. Ask the agent: “Read the room, list open risks, run a 60-minute forecast, and stage a containment response plus a customer update.”
3. Show the forecast and both staged cards appear without the agent clicking through the board.
4. Emphasize that neither proposal has changed the official decision log. Approve the response and communication with the visible human buttons. Metrics, objective progress, resource allocation, and the activity trail update together.
5. Switch the agent role to **Facilitator**. The WebMCP tool count changes. Ask the agent to create a vendor failure inject and advance time by 30 minutes.
6. Show pressure increase and any overdue objective. Ask the facilitator to resolve the original timeout inject after the team response.
7. Ask the agent to stage a closeout with three lessons. End at the closeout gate: there is no agent close tool; only the human confirmation can close and export the after-action record.

Suggested coach prompt:

> Read this room. Identify the biggest open risks, run a deterministic 60-minute forecast with seed 42, stage one conservative containment response that advances a critical objective, and draft a factual customer update. Do not claim either item is approved.

Suggested facilitator prompt:

> Create a severity-3 vendor inject that activates now, advance the clock 30 minutes, then summarize how the board changed. Do not approve any response proposal.
